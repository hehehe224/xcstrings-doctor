# Contributing

Small, focused changes are welcome.

1. Open an issue for behavior changes or new checks.
2. Add a minimal `.xcstrings` fixture that reproduces the case.
3. Add or update a test.
4. Run `npm run check`, `npm test`, and `npm pack --dry-run`.

Findings must be deterministic, explain the recovery, and avoid modifying a catalog. New runtime dependencies need a clear justification.
